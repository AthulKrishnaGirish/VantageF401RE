# Validation Results

This folder will contain the electrical and PCB validation results generated during the development of the VantageF401RE board.

## Planned Validation

### ERC — Electrical Rules Check

ERC will be performed after completing the schematic to identify electrical connection issues, incorrect power connections, unconnected pins and other schematic-level problems.

### DRC — Design Rules Check

DRC will be performed after completing the PCB layout to check clearances, track connections, board-edge constraints, footprint issues and other PCB design-rule violations.

## Final Validation Files

The final project documentation will include:

- ERC result/report
- DRC result/report
- Final schematic PDF
- Final PCB layout PDF
- PCB 3D visualization
- Final BOM and estimated component cost

Validation results will be added to this folder as the design progresses.
